# javascript-DOM-project

Proyecto de ejemplo que muestra interacciones con el DOM usando JavaScript puro (Vanilla JS).

## Descripción
Aplicación pequeña para practicar manipulación del DOM: selección de elementos, manejo de eventos, creación y actualización dinámica de contenido, y uso de plantillas simples.

## Características
- Manipulación del DOM (selectores, clases, atributos).
- Manejo de eventos (click, input, submit).
- Renderizado dinámico de listas y formularios.
- Código modular y fácil de extender.

## Requisitos
- Navegador moderno (Chrome, Firefox, Edge).
- Node.js (opcional, solo para servir archivos localmente).

## Cómo ejecutar
1. Clonar o descargar el repositorio.
2. Abrir `index.html` directamente en el navegador
    o servir con un servidor local:

    - Con Node (http-server):
      ```
      npm install -g http-server
      http-server .
      ```
    - Con Live Server (VS Code): botón "Go Live".

3. Navegar a `http://localhost:8080` (o el puerto que indique el servidor).

## Estructura de archivos
- index.html — HTML principal.
- /css/
  - styles.css — Estilos.
- /js/
  - app.js — Lógica principal de DOM.
  - utils.js — Funciones auxiliares.
- README.md — Este archivo.
